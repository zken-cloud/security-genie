Security Genie

A portable security-specialist harness and skill pack for coding agents — Claude Code, Antigravity, Codex, Gemini CLI. It turns a general agent into a Google Cloud platform security specialist that inspects real environments, reviews architecture and Terraform, and prepares you for the customer's security team.

The four sessions

#SessionMinWhat you build
1 Harness & MCP 30 Operating contract, gcloud + SecOps + GTI MCP, multi-account credentials, guard hook
2 Architecture & IaC skills 45 Well-architected, GCMVSP, Terraform least-privilege review and generation
3 Conversation skills 45 Jargon translator, objection handling

Before you start

  • MCP & credentials setup — gcloud, SecOps and GTI. Provision CHRONICLE_* and VT_APIKEY before session 1; key provisioning is the most common overrun.
  • Python 3.11+ and uv for the SecOps and GTI servers.
  • For session 4: the ability to create a disposable GCP project and link billing — verify this a week ahead.
  • Facilitators: facilitator guide.

Never deploy examples/flawed-agent-app. It is deliberately exploitable — public bucket, open bastion, SQL-injectable app. You deploy only the fixed Terraform, only into a project you created for the purpose. See the smoke-test runbook.
